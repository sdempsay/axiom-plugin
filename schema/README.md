# Catalog schema

JSON Schema 2020-12 for `catalog.yaml` is [`axiom-catalog-1.json`](axiom-catalog-1.json) (`schemaVersion: 1`).

The Java model in `axiom-model` parses YAML and applies the same required-field rules, plus uniqueness, snippet-file existence, and regex compilation.

Examples here are fixtures for that validator. See [C1](https://github.com/sdempsay/axiom/blob/master/prds/C1-catalog-schema.md).
